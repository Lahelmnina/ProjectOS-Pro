# ProjectOS Pro — Personal Operating System for Human Productivity

Добро пожаловать в **ProjectOS Pro** — не просто приложение для задач, а полноценную персональную операционную систему для управления проектами, знаниями, целями, временем, ресурсами и действиями человека.

Это уникальное сочетание лучших качеств **Notion**, **Linear**, **Jira**, **Obsidian**, **Things 3**, **Apple Ecosystem**, **Motion**, **Raycast** и автономных **AI Agents (ChatGPT)**.

---

## 🚀 Как запустить локально

Для запуска операционной системы на локальной машине выполните следующие шаги:

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/Lahelmnina/ProjectOS-Pro.git
   cd ProjectOS-Pro
   ```

2. **Установите зависимости**:
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Запустите сервер разработки**:
   ```bash
   npm run dev
   ```

4. **Откройте в браузере**:
   Перейдите по адресу [http://localhost:3000](http://localhost:3000).

## ⚡ Как задеплоить на Vercel (Пошагово)

Деплой на **Vercel** занимает менее 1 минуты благодаря встроенной поддержке Next.js:

1. **Зайдите на Vercel**:
   Перейдите на сайт [vercel.com](https://vercel.com) и войдите под своим аккаунтом **GitHub**.

2. **Импортируйте проект**:
   - Нажмите синюю кнопку **"Add New"** в правом верхнем углу и выберите **"Project"**.
   - Найдите ваш репозиторий `ProjectOS-Pro` в списке репозиториев GitHub и нажмите **"Import"**.

3. **Настройки сборки (Build Settings)**:
   - Vercel автоматически распознает Next.js!
   - Параметры по умолчанию будут настроены идеально:
     - **Framework Preset**: `Next.js`
     - **Build Command**: `next build`
     - **Output Directory**: `.next`

4. **Переменные окружения (Environment Variables)**:
   - Если вы планируете подключить реальные API ключи для LLM в будущем, вы можете добавить их здесь (например, `OPENAI_API_KEY`). Для текущей версии с имитацией AI это поле можно оставить пустым.

5. **Деплой**:
   - Нажмите кнопку **"Deploy"**. Через 30-45 секунд проект будет собран, и вы получите персональный рабочий URL-адрес вида `https://projectos-pro.vercel.app`.

## 💻 20 Интерактивных Экранов Внутри

Система включает в себя полную реализацию всех 20 экранов с интерактивным переключением через боковое меню или поисковую консоль **Spotlight (⌘K)**:

1. **Splash Screen** — футуристичная загрузка ядра ОС, проверка целостности нейросетевых ключей и системные логи дешифрования.
2. **Authentication** — шлюз авторизации с симулятором сканирования отпечатка пальца и сетчатки глаза.
3. **Onboarding AI Setup** — пошаговый калибратор жизненных целей (Vision → Goals → Projects → Tasks).
4. **Main Command Center** — центральный Dashboard: энергия, уровень фокуса, утренняя сводка AI и Priority Engine.
5. **Projects Dashboard** — интерактивная сетка вселенных проектов с радиальными шкалами бюджетов и задач.
6. **Project Detail** — подробный разбор проекта (например, *DriverPilot AI*) с роадмапом, вехами и диалогом с AI PM.
7. **Task Manager** — интерактивный планировщик задач **Task Engine 3.0** с детализацией энергозатрат и ИИ-декомпозицией.
8. **Smart Calendar** — планировщик блоков времени, сессии глубокой работы (Deep Work) и Pomodoro-таймер.
9. **AI Project Manager** — диалоговый терминал автономного координатора, предупреждающий о простоях и создающий спасительные спринты.
10. **Knowledge Base** — "Второй мозг" для Markdown-заметок с автоматическим связыванием понятий.
11. **Semantec Graph View** — интерактивная карта связей Obsidian-Style, отрисованная на SVG с неоновыми связями между задачами и целями.
12. **Memory Center** — журнал решений, извлеченных уроков и прошлых ошибок, помогающий избегать повторных багов.
13. **Goals Architecture** — стратегическая пирамида целей для отслеживания цепочки влияния действий на общую картину жизни.
14. **Habits Matrix** — матрица привычек в стиле Cyberpunk Heatmap, отражающая ежедневную калибровку состояния.
15. **Capital Monitor** — финансовый менеджер SaaS-платформы с графиком транзакций и рекомендациями ИИ по экономии на GPU-кластерах.
16. **Neural Analytics** — аналитические графики и индексы стабильности работы мозга на основе энергозатрат.
17. **Automation Flows** — внутренний Zapier: визуальный конструктор правил реагирования (например, "Если просрочено → AI переносит срок").
18. **Agent Marketplace** — выбор и активация специализированных ИИ-агентов (PM, Research, Coding, Finance, Life Coach, Security).
19. **System Settings** — настройки локального шифрования zero-knowledge, бэкапов и переключения офлайн-режима.
20. **Neuro Profile** — сводка профиля пользователя с сертификатами, уровнем фокусировки и достигнутыми вехами.
